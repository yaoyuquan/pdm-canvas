# New-model templates

Blank Physical Data Models used by "新建模型". Each holds one empty model with
one empty diagram; `src/pdm/template.ts` gives every new model fresh GUIDs,
creation time, and creator. Never edit these files by hand.

| File | DBMS (PowerDesigner name) | DBMS definition |
|---|---|---|
| `oracle11g.pdm` | ORACLE Version 11g | `ora11g.xdb` |
| `mysql50.pdm` | MySQL 5.0 | `mysql50.xdb` |
| `postgresql9.pdm` | PostgreSQL 9.x | `pgsql9.xdb` |

## How they were made

Generated by PowerDesigner **16.7.5.6978** through COM automation (PowerShell):

```powershell
$pd = New-Object -ComObject PowerDesigner.Application
# -840675807 = PdPDM.cls_Model (from Interop.PdPDM.dll)
$m = $pd.CreateModel(-840675807, "|DBMS=MySQL 5.0|Diagram=PhysicalDiagram")
$m.Name = 'NewModel'; $m.Code = 'NewModel'
$m.Save('C:\path\mysql50.pdm'); $m.Close(0)
```

Use `|DBMS=...`; `|Language=...` is silently ignored and yields Oracle 11g.

After saving, two things were cleaned up: the `<a:RepositoryFilename>` line
(the local save path) was removed, and `Creator`/`Modifier` were set to
`PDMCanvas`. Line endings stay CRLF (`.gitattributes`: `*.pdm -text`).
